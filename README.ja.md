## 📖 概要

**高精度身分証・契約書ジェネレーター**は、美麗かつリアルな各種身分証明書、登録契約書、証明証書を作成・高画質書き出しできるレスポンシブWebアプリケーションです。

HTML5、TailwindCSS、ES6の標準Web技術のみで構築されており、**バックエンドサーバーを一切使用しません**。アップロードした写真や入力データはすべてブラウザ内で処理され、**100% のプライバシー安全**が保証されます。実物印刷に耐えうる **300 PPI（CR80カード: 1011 × 638 px、A4証明書: 850 × 1200 px）** の極めて鮮明な画質で出力可能です。

---

## ✨ 主な特長

- **🔒 100% 完全クライアント側処理（オフライン対応）**：
  顔写真のトリミング、位置調整、拡大縮小、カードのレンダリングおよび書き出しはすべてブラウザの Canvas API を使用してローカルで実行されます。個人情報や画像が外部サーバーに送信されることは一切ありません。
- **💎 300 PPI 超高解像度・実寸印刷対応**：
  一般的なカード規格である **CR80（85.6 mm × 54.0 mm @ 300 PPI = 1011 × 638 px）** に準拠。原寸（1X）保存に加え、さらに高精細な 2X 印刷用保存に対応しています。
- **🌐 多言語対応（i18n）**：
  **日本語**、**英語**、**簡体字中国語**、**繁体字中国語** の4言語をサポート。端末の言語設定（`navigator.languages`）を自動検出し、リスト外の言語の場合は自動的に英語へフォールバックします。ヘッダーの選択メニューからいつでも手動切り替えが可能です。
- **🎨 4つの独立した洗練されたテンプレート**：
  - **テンプレート1: 奴隷身分カード**：方眼紙テクスチャ、ホログラム認可ステッカー、固有識別コード、服従誓約。
  - **テンプレート2: 専属身分証明書**：ディープパープルのウェーブヘッダー、スペードと五ツ星の紋章、18項目の属性チェックリスト、「YES MASTER」バナー、バーコード。
  - **テンプレート3: 登録契約証明書**：ヴィンテージ羊皮紙の質感、二重飾り枠、角度調節可能な朱色の公認印章、ベクターQRコード、正式規約条項。
  - **テンプレート4: 両面認識カード**：表面（スリーサイズ、特技属性タグ、英字筆記体サイン）と裏面（11か条の遵守事項、展示写真A/Bスロット、ピンクQRコード、両面一括zip保存および結合画像保存対応）。
- **🔄 ピュア CSS 3D 両面反転アニメーション (v1.1)**：
  テンプレート4には、CSS 3D Transforms（`preserve-3d` および `backface-visibility: hidden`）を採用した物理的な反転アニメーションを搭載。外部ライブラリなしで表裏両面のスムーズなプレビュー切り替えが可能です。
- **💡 モジュール式誓約・インスピレーション文案ライブラリ (v1.2)**：
  サイドバーから呼び出せるモーダル式文案ライブラリ。4つのシチュエーション（🐶 忠犬拘束、💧 極度調教、👠 執務官陥落、⚖️ 厳格規訓）を4言語で網羅。ワンクリックで誓約文、格言、規約条項、規則リストへ直接入力または追加入力できます。
- **🏷️ ヴィンテージ公文書消印＆3Dエンボス刻印システム (v1.2)**：
  全テンプレート（1〜4）に対応したベクターSVGオーバーレイシステム。かすれ波線消印（4本の平行ウェーブ＋日付官庁丸印）と3D浮き彫りエンボス刻印（36ポイント精密星形ギザギザ＋立体シャドウフィルター）を搭載。顔写真被せ、右下、左下のプリセット配置に加え、位置、角度（-45°〜+45°）、透明度、4色のインクカラーをリアルタイム調整可能です。
- **🎲 多言語対応ランダム設定（インスピレーション文案）**：
  各テンプレートに4言語対応の文案プリセットを収録。サイコロ（🎲）をクリックするだけで、写真を保持したまま魅力的な設定文案をワンクリック反映できます。
- **💾 自動下書き保存（LocalStorage）**：
  入力内容はローカルストレージへリアルタイムで自動保存され、ページの再読み込みや再訪時にも編集内容が復元されます。
- **📱 モバイル対応・タッチジェスチャー操作**：
  スマートフォン画面に最適化された「入力フォーム」と「プレビュー」の切り替え、ピンチ操作による直感的なズーム＆パン操作に対応しています。

## 🚀 使い方・ローカル起動

### 1. ローカルサーバー起動
本プロジェクトは静的ファイルのみで構成されているため、特別なビルド環境は不要です：

```bash
# リポジトリをクローン
git clone https://github.com/amberch872/Slut-ID-Generator.git
cd Slut-ID-Generator

# 簡易HTTPサーバーを起動（Python 3 の例）
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてご利用ください。

### 2. 品質検証テストの実行
DOM IDの一意性、イベントハンドラーの整合性、印刷規格の正確性、i18n辞書の完全性を検証します：

```bash
node test_suite.js
```

## 📖 项目简介

**证件与协议高保真工坊** 是一款轻量级、响应式的个性化身份识别卡、契约登记证书与情趣明信片生成系统。

项目基于纯原生前端技术构建（HTML5 + TailwindCSS + ES6 模块），**零后端服务依赖**，**100% 保护用户隐私**。生成的证件严格按照物理印刷标准输出：**CR80 标准卡片与明信片为 300 PPI（1011 × 638 px），A4 登记证书为 850 × 1200 px**。

---

## ✨ 核心特性

- **🔒 100% 纯前端离线隐私保护**：
  所有上传的头像、照片调整、表单字段与图片导出均在浏览器沙箱内存中直接通过 HTML5 Canvas 与本地 JSZip 处理，绝不向任何远程服务器上传任何个人隐私数据或图像。
- **💎 300 PPI 实体印刷级超清分辨率**：
  严格对标真实身份卡与明信片物理尺寸（**85.6 mm × 54.0 mm** @ 300 PPI = **1011 × 638 px**），支持 1X 标准原图与 2X/3X 极清印刷模式导出。
- **🌐 全面适配国际化（i18n）**：
  支持 **简体中文**、**繁體中文**、**英文** 与 **日本語** 4 种语言。根据访问设备系统语言智能自动切换；未在支持列表中的设备语言一律默认兜底回退为英文。
- **🎨 五套独立精美主题模版**：
  - **模版一：奴隶身份卡**：经典网格纸底纹、全息防伪贴纸、专属条形码徽章与服从誓词。
  - **模版二：身份证**：深紫高光波浪顶栏、黑桃金星徽章、18 项玩法服从清单、“YES MASTER” 誓约横幅与条形码。
  - **模版三：登记证书协议**：复古泛黄羊皮纸质感、双重花纹边框、角度可自由旋转的官方红色印章、矢量核验二维码与正式条款列表。
  - **模版四：极清双面识别卡**：包含正面档案（三围体态、特长属性标签、花体签名）与背面规范（11 条使用守则、展品 A/B 照片位、粉色专属二维码；支持正反打包下载与长图合并导出）。
  - **模版五：母畜明信片 (v2.0)**：全新独立双面明信片系统，对标并超越 `bennadel/Kinky-eCards`。正面为高清海报写真（支持全幅无界、复古拍立得、古典邮政三种相框与暗角/暖调/赛博滤镜）；背面为法式经典 CARTE POSTALE 档案卡纸（6 位邮编方格、私密手写书法情话、6 款专属矢量情趣邮票、盖销波浪戳、动态日期、双栏寄件人/收件犬规整横线地址栏）。
- **💌 完整明信片投递与打包系统 (v2.0)**：
  支持正面单面、背面单面、正反双面合并长图，以及基于纯前端本地 JSZip 的双面超清原图 ZIP 归档包导出（含 `01_front.png`、`02_back.png` 及投递机密清单 TXT）。
- **🔄 纯 CSS 3D 双面卡片翻转动效 (v1.1 & v2.0)**：
  模版四与模版五均采用纯 CSS 3D Transforms（`preserve-3d` 与 `backface-visibility: hidden`）实现真实丝滑的卡片翻转物理动效，无需任何外部动画库，流畅查看与切换正反两面。
- **💡 模块化誓言与批注灵感库 (v1.2 & v2.0)**：
  侧栏集成专属弹窗式灵感文库，覆盖四大特色分类（🐶 忠犬拘束、💧 极度调教、👠 长官沦陷、⚖️ 严酷规训），提供四种语言的高质量文案。支持一键直接替换或追加填入卡片誓词、语录、条款、规训细则与明信片私密寄语中。
- **🏷️ 复古档案波浪邮戳与防伪钢印贴纸系统 (v1.2)**：
  全新矢量 SVG 防伪与盖印层，全模版无缝覆盖。提供**破损做旧波浪邮戳**（四道平行波浪线 + 环形机构日期章）与**3D 浮雕压纹钢印**（36 齿精密花边星芒 + 立体光影滤镜）。支持照片遮盖、右下角、左下角预设位置，并可实时微调平移、旋转倾斜角度（-45° ~ +45°）、透明度与 4 种复古印泥色系。
- **🖼️ 视觉资产重制与预设头像库 (v1.3)**：
  模板视觉元素全面高清化：模版 1 升级高密毫米坐标线网格与倾斜机密档案水印层；模版 2 彻底重构黑桃 Q 徽章为 24K 晶体黄金矢量（`crest_gold.svg`），印章与条码升级为纯矢量 SVG；模版 3 引入复古欧洲双层羊皮纸底纹（`parchment_texture.svg`）与齿轮点阵微缩防伪、立体刻面五角星公章；模版 4 新增沦陷实录法医微距证物附图。全部模板增设内置高清预设寸照与写真图库（经典支配、冷艳项圈、绝密档案、沦陷实录等），支持一键快选切换与微调复位。
- **🎲 多语言灵感人设文案库**：
  针对 5 款模版分别内置四种语言的灵感人设文案。点击骰子（🎲）一键快速填入，同时保持当前照片完好无损。
- **💾 本地草稿自动保存与恢复**：
  内置防抖 LocalStorage 暂存引擎，编辑过程中自动记录表单输入，刷新或重新打开页面时自动恢复上次草稿。
- **📱 移动端画中画实时微缩预览与自适应排版引擎 (v2.1)**：
  移动端支持全新的【画中画（PiP）浮动微缩卡片】实时预览机制。在填写表单时，右下角悬浮半透明 mini 卡片预览窗，表单输入实时同步渲染；支持点击一键切换全屏预览、双面卡片即时翻转、以及一键收起为极简半透明胶囊 Pill；当软键盘唤起时自动半透明避让以防遮挡输入。同时搭载**字符上限与溢出预警引擎**，核心字段实时提示接近或超出字数上限，杜绝排版破版。
- **🛡️ 纯本地零泄露隐私横幅与多风格隐私遮挡工坊 (v2.1)**：
  全模板照片位均常驻醒目「🛡️ 100% 纯本地离线处理 · 物理级零上传隐私保障」安全盾牌横幅，彻底打消私密照片泄漏顾虑。集成**九宫格黄金分割对齐构图线**（Rule-of-Thirds 9-Grid Overlay）与手势触控平移/双指捏合缩放；全模板通用**隐私遮挡工坊（Censorship & Privacy Studio）**，支持机密黑条（Bar）、魅魔心形（Heart）、档案条码（Barcode）、高斯马赛克模糊（Mosaic）与无遮挡 5 种风格，配备自定义标语文字、水平/垂直位移与倾斜旋转微调滑块。
- **📱 移动端自适应视口与手势缩放**：
  手机端提供【表单填写】与【实时预览】无缝切页，支持单指平移、双指捏合缩放卡片。

## 🚀 快速开始与本地开发

### 1. 本地启动运行
本项目为纯静态结构，无需安装复杂的构建工具或 Node 服务依赖：

```bash
# 克隆代码仓库
git clone https://github.com/amberch872/Slut-ID-Generator.git
cd Slut-ID-Generator

# 启动本地静态服务器 (支持 Python 3)
python3 -m http.server 8080
```

启动后在浏览器中访问 `http://localhost:8080` 即可畅爽体验。

### 2. 运行自动化测试套件
项目配备了完整的自动化验证脚本，可直接检验 DOM 唯一性、事件绑定合法性、印刷分辨率标准与多语言字典一致性：

```bash
node test_suite.js
```

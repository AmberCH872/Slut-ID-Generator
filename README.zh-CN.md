## 📖 项目简介

**证件与协议高保真工坊** 是一款轻量级、响应式的个性化身份识别卡与契约登记证书生成系统。

项目基于纯原生前端技术构建（HTML5 + TailwindCSS + ES6 模块），**零后端服务依赖**，**100% 保护用户隐私**。生成的证件严格按照物理印刷标准输出：**CR80 标准卡片为 300 PPI（1011 × 638 px），A4 登记证书为 850 × 1200 px**。

---

## ✨ 核心特性

- **🔒 100% 纯前端离线隐私保护**：
  所有上传的头像、照片调整、表单字段与图片导出均在浏览器沙箱内存中直接通过 HTML5 Canvas 处理，绝不向任何远程服务器上传任何个人隐私数据或图像。
- **💎 300 PPI 实体印刷级超清分辨率**：
  严格对标真实身份卡物理尺寸（**85.6 mm × 54.0 mm** @ 300 PPI = **1011 × 638 px**），支持 1X 标准原图与 2X 极清印刷模式导出。
- **🌐 全面适配国际化（i18n）**：
  支持 **简体中文**、**繁體中文**、**英文** 与 **日本語** 4 种语言。根据访问设备系统语言智能自动切换；未在支持列表中的设备语言一律默认兜底回退为英文。
- **🎨 四套独立精美主题模版**：
  - **模版一：奴隶身份卡**：经典网格纸底纹、全息防伪贴纸、专属条形码徽章与服从誓词。
  - **模版二：身份证**：深紫高光波浪顶栏、黑桃金星徽章、18 项玩法服从清单、“YES MASTER” 誓约横幅与条形码。
  - **模版三：登记证书协议**：复古泛黄羊皮纸质感、双重花纹边框、角度可自由旋转的官方红色印章、矢量核验二维码与正式条款列表。
  - **模版四：极清双面识别卡**：包含正面档案（三围体态、特长属性标签、花体签名）与背面规范（11 条使用守则、展品 A/B 照片位、粉色专属二维码；支持正反打包下载与长图合并导出）。
- **🎲 多语言灵感人设文案库**：
  针对 4 款模版分别内置四种语言的灵感人设文案。点击骰子（🎲）一键快速填入，同时保持当前照片完好无损。
- **💾 本地草稿自动保存与恢复**：
  内置防抖 LocalStorage 暂存引擎，编辑过程中自动记录表单输入，刷新或重新打开页面时自动恢复上次草稿。
- **📱 移动端自适应视口与手势缩放**：
  手机端提供【表单填写】与【实时预览】无缝切页，支持单指平移、双指捏合缩放卡片。

## 🚀 快速开始与本地开发

### 1. 本地启动运行
本项目为纯静态结构，无需安装复杂的构建工具或 Node 服务依赖：

```bash
# 克隆代码仓库
git clone https://github.com/amberch872/Slut-ID-Generator.git
cd Slut-ID-Generator

# 启动本地静态服务器 (支持 Python 3)
python3 -m http.server 8080
```

启动后在浏览器中访问 `http://localhost:8080` 即可畅爽体验。

### 2. 运行自动化测试套件
项目配备了完整的自动化验证脚本，可直接检验 DOM 唯一性、事件绑定合法性、印刷分辨率标准与多语言字典一致性：

```bash
node test_suite.js
```

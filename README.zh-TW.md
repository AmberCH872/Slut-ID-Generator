## 📖 專案簡介

**證件與協議高保真工坊** 是一款輕量級、響應式的個人化身份識別卡與契約登記證書生成系統。

專案基於純原生前端技術構建（HTML5 + TailwindCSS + ES6 模組），**零後端伺服器依賴**，**100% 保障用戶隱私**。生成的證件嚴格遵循實體印刷規格輸出：**CR80 標準卡片為 300 PPI（1011 × 638 px），A4 登記證書為 850 × 1200 px**。

---

## ✨ 核心特性

- **🔒 100% 純前端離線隱私保護**：
  所有上傳的個人頭像、照片調整、表單數據與圖片輸出均直接在瀏覽器記憶體中透過 HTML5 Canvas 處理，絕不上傳任何個人資料至任何遠端伺服器。
- **💎 300 PPI 實體印刷級極清解析度**：
  嚴格對照實體身分卡標準尺寸（**85.6 mm × 54.0 mm** @ 300 PPI = **1011 × 638 px**），支援 1X 標準原圖與 2X 極清印刷模式導出。
- **🌐 完整國際化支援（i18n）**：
  支援 **繁體中文**、**簡體中文**、**英文** 與 **日本語** 4 款語言。根據用戶裝置的系統設定自動匹配，不在列表內的語系預設平滑退回為英文。
- **🎨 四大精緻主題模版**：
  - **模版一：奴隸身分卡**：方格網紋底圖、全息防偽貼紙、專屬條碼識別標章與服從誓約。
  - **模版二：身分證**：深紫高光波浪頂欄、黑桃金星徽標、18 項玩法服從清單、「YES MASTER」標語與條碼。
  - **模版三：登記證書協議**：復古仿舊羊皮紙質、雙層古典邊框、可自由調整旋轉角度的官方紅印章、向量核驗 QR Code 與正式契約條款。
  - **模版四：極清雙面識別卡**：正反雙面設計；正面展示三圍體態、特長標籤與英文花體簽名，背面包含 11 條使用守則、展品 A/B 照片欄、專屬粉色 QR Code，支援正反打包下載與長圖合併輸出。
- **🔄 純 CSS 3D 雙面卡片翻轉動效 (v1.1)**：
  模版四運用純 CSS 3D Transforms（`preserve-3d` 與 `backface-visibility: hidden`）實現極具立體感之卡片翻轉物理動效，不耗費額外資源即可平順預覽正反面。
- **💡 模組化誓言與批註靈感庫 (v1.2)**：
  側欄整合彈窗式靈感庫，收納四大風格情境（🐶 忠犬拘束、💧 極度調教、👠 長官淪陷、⚖️ 嚴酷規訓），支援四種語言之精緻文本。支援一鍵取代或追加填寫至誓約、格言、條款與細則中。
- **🏷️ 復古檔案波浪郵戳與防偽鋼印貼紙系統 (v1.2)**：
  全新向量 SVG 鋼印防偽圖層，支援所有模版（模版 1-4）。提供**仿舊波浪消印郵戳**（四道平行波浪線 + 圓形機構日期戳）與**3D 浮雕立體鋼印**（36 齒精緻星芒邊框 + 浮雕立體光影濾鏡）。支援照片局部遮蓋、右下角、左下角等預設位置，並可自由平移、傾斜旋轉（-45° ~ +45°）、微調透明度與切換 4 款復古墨水配色。
- **🖼️ 視覺資產重製與預設頭像庫 (v1.3)**：
  前四個模板視覺元素全面高畫質化：模版 1 升級高密毫米坐標線網格與傾斜機密檔案浮水印層；模版 2 徹底重構黑桃 Q 徽章為 24K 晶體黃金向量（`crest_gold.svg`），印章與條碼升級為純向量 SVG；模版 3 引入復古歐洲雙層羊皮紙底紋（`parchment_texture.svg`）與齒輪點陣微縮防偽、立體刻面五角星公章；模版 4 新增淪陷實錄法醫微距證物附圖。全部 4 套模板增設內建高畫質預設證件照與寫真圖庫（經典支配、冷艷項圈、絕密檔案、淪陷實錄等），支援一鍵快選切換與微調復位。
- **🎲 多語系靈感人設文案庫**：
  為 4 款模版各自準備了 4 種語言的靈感人設。點擊骰子（🎲）即可一鍵填入精彩設定，且絕不覆蓋當前已上傳的照片。
- **💾 本地草稿自動暫存與復原**：
  內建防抖 LocalStorage 暫存引擎，表單編輯即時自動記錄，重新整理或回訪時能自動還原上次草稿。
- **📱 行動端自適應視口與手勢縮放**：
  手機端支援【表單填寫】與【即時預覽】快速切換，支援手勢平移與雙指捏合縮放畫布。

## 🚀 快速上手與本地測試

### 1. 本地啟動
專案採用純靜態架構，不依賴任何外部編譯建置環境：

```bash
# 複製專案庫
git clone https://github.com/amberch872/Slut-ID-Generator.git
cd Slut-ID-Generator

# 啟動本地靜態伺服器
python3 -m http.server 8080
```

隨後開啟瀏覽器造訪 `http://localhost:8080` 即可預覽使用。

### 2. 執行自動化測試
使用內建的驗證工具確認 HTML DOM 唯一性、函式連結完整性及 i18n 字典一致性：

```bash
node test_suite.js
```
